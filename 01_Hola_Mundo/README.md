# 01 - Hola Mundo

## Objetivo

Aprender la estructura básica de un programa en C++ y utilizar la salida estándar para imprimir texto en pantalla.

## Conceptos aprendidos

- Estructura de un programa en C++
- "#include <iostream>"
- Función "main()"
- "std::cout"
- operador "<<"
- instrucción "return 0;"
- Compilación y ejecución

## Archivos

- "main.cpp"

## Cómo ejecutar el proyecto

1. Abrir la solución "01_Hola_Mundo.sln" con Visual Studio Community 2026.
2. Presionar **Ctrl + F5** para compilar y ejecutar.
3. Deberá mostrarse el siguiente resultado:

```
Hello World!
```

## Lo que aprendí

- "#include <>" es una directiva del preprocesador, sirve para llamar a bibliotecas u otros
  archivos al programa antes de que se compile el programa.
- "iostream" es una biblioteca o header para tener acceso a objetos y funciones específicas,
  en este caso a la entrada y salida de flujo.
- "int" es una palabra reservada que indica el tipo de dato de un objeto, variable o función.
- "main" es la palabra reservada que representa a la función principal de todo programa.
- "{}" las llaves indican el inicio y fin del conjunto de todas las instrucciones de una función o clase.
- "std" es una palabra que indica un espacio de nombre "namespace" que sirve para especificar un objeto en él
  y no tener conflictos con nombres iguales.
- "::" es al operador de ámbito de resolución y sirve para indicar que un objeto es llamado desde cierto namespace.
- "cout" es un objeto de la biblioteca iostream que permite una salida de flujo al ejecutar y así mostrar "algo".
- "<<" es un operador de inserción y sirve para integrar "algo" dentro de un objeto.
- ""Hello World!"" las dobles comillas sirven para crear y/o mostrar uno o varios caractres en forma de cadena.
- "\n" sirve para representar un salto de línea.
- ";" es el símbolo usado para representar el fin de una instrucción.
- "return" es una palabra reseverbada para devolver un valor en donde fue llamada una función.
- "0" es un valor de tipo entero que indica en este caso que el programa al finalizar devuelve un valor nulo
  y ha finalizado correctamente.
- El compilador transforma el código fuente en un programa ejecutable.
